П'ята full-page HTML — що це?

A, B, C, D вже підтверджено. Обираємо п'яту:

E

Author / Speaker Profile

Профіль автора або спікера. Природньо: <audio> для вимови імені, <ruby> для імені в оригінальному script, <q cite> для цитат автора, <time datetime> для дат конференцій/публікацій, <video> для recorded talks, <dialog> для bio popup, <dl><dt> для facts/credentials.

F

News Article / Press Release

Новинна стаття. Природньо: <time datetime> для дати публікації та подій, <q cite> для прямої мови з джерелом, <video>/<audio> для media embeds, <hr> named styles між секціями, <dialog> для "related stories", <ruby> для іноземних імен.

G

Museum / Exhibition Entry

Опис музейного експонату або виставки. Природньо: <ruby> для назв мовою оригіналу, <time datetime> для датування (~3000 BCE), <q cite> для цитат з каталогів, <audio> для audio guide, <video> для 3D tour, <dialog> для provenance details, <dl><dt> для metadata (матеріал, розміри, місцезнаходження).

H

Academic Abstract / Research Paper

Академічна стаття з абстрактом. Природньо: <ruby> для термінів різними мовами, <q cite> для цитат джерел з DOI/URL, <time datetime> для дат подання/прийняття, <hr> між розділами, <dl><dt> для metadata, <dialog> для footnotes/references.
