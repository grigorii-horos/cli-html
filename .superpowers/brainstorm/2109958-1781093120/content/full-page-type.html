Яким контентом наповнити нову full-page HTML showcase?

Сторінка має природньо використовувати нові фічі: <dialog>, <video>/<audio>, <ruby>, <time datetime>, <q cite>, named <hr> styles, <dt> suffix

A

Technical Article

Стаття про веб-технологію або мову. Природньо: <q cite> для цитат зі специфікацій, <ruby> для термінів з іноземних мов, <time datetime> для дат публікацій/версій, <hr> між секціями, <dialog> для "read more" блоків, <video> для демо-роликів.

Схоже на поточний documentation.html, але з новими елементами

B

Recipe / How-To

Кулінарний рецепт або інструкція. Природньо: <ruby> для назв страв азійської кухні, <time datetime> для часу приготування (ISO duration), <audio> для вимови, <dl><dt> для інгредієнтів з кількістю, <hr> між кроками, <dialog> для tips/warnings, <q cite> для джерела рецепту.

Унікальний сценарій — жоден з поточних full pages такого не має

C

Changelog / Release Notes

Журнал змін проекту. Природньо: <time datetime> для дат релізів, <hr> різних стилів між версіями, <q cite> для цитат з issues/PRs, <dialog> для migration notes, <video> для demo записів, <dl><dt> для breaking changes.

Але changelog.html вже є в markdown full — дублювання

D

Glossary / Encyclopedia Entry

Глосарій або стаття-енциклопедія. Природньо: <ruby> для транскрипції термінів, <dl><dt> для визначень (з suffix ::), <q cite> для авторських цитат з посиланнями, <time datetime> для дат першого вживання, <audio> для вимови, <hr> між літерами, <dialog> для expanded definitions.

Максимальне покриття нових фіч в одному документі
