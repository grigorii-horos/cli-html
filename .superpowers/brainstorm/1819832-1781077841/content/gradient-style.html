Gradient Text — Style

Як має виглядати градієнтний текст? (емулюємо ANSI-кольори через CSS)

A

Rainbow (7 кольорів ANSI по символах)

Кожен символ — наступний колір спектру. Яскраво, ретро.

Hello, World!

Активується через data-cli-gradient="rainbow" або gradient: rainbow у темі

B

Два кольори (start → end)

Плавний перехід між двома ANSI-кольорами. Елегантно.

Hello, World!

data-cli-gradient="pink,cyan" — будь-які два ANSI-кольори

C

Named presets + custom

Набір вбудованих preset-ів + можливість задати свої кольори.

sunset ← preset: "sunset"
ocean ← preset: "ocean"
neon ← preset: "neon"

data-cli-gradient="sunset" або data-cli-gradient="red,yellow,green"
