Callout Rendering Style

How should callouts look in the terminal?

A

Left border + icon prefix

Colored vertical bar on the left, icon + type label on first line. Like GitHub Markdown alerts.

│ ✓ NOTE
│ This is important information about
│ the current topic.

│ ⚠ WARNING
│ Be careful when doing this.
B

Full box border

Complete box with rounded/single borders, colored header line.

╭─ ✓ NOTE ─────────────────╮
│ This is important info    │
│ about the current topic.  │
╰──────────────────────────╯

╭─ ⚠ WARNING ──────────────╮
│ Be careful when doing     │
│ this.                     │
╰──────────────────────────╯
C

Left border + indented content (no box)

Minimalist. Just colored bar + indented text. No right border.

✓ Note
▌ This is important information
▌ about the current topic.

⚠ Warning
▌ Be careful when doing this.
D

Config-driven: default = left border, override до box

За замовчуванням — стиль A (лівий бордер). Через config.yaml або data-cli-style — можна змінити на box.

callout:
  style: border  # border | box
  note:
    color: green
    icon: ✓
  warning:
    color: yellow
    icon: ⚠
