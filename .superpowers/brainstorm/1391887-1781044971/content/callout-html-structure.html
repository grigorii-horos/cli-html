Callout Boxes — HTML Structure

How should callouts be written in HTML? Pick the approach that feels most natural.

A

<aside class="note">

Semantic HTML5. Uses existing <aside> tag with class to specify type.

<aside class="note">
  This is a note.
</aside>

<aside class="warning">
  Be careful here!
</aside>

Pros

  • Standard HTML5 element
  • Works in browsers too

Cons

  • <aside> currently renders as plain div
B

data-cli-callout="note" attribute

Any block element gets callout styling via a custom attribute.

<div data-cli-callout="note">
  This is a note.
</div>

<blockquote data-cli-callout="warning">
  Be careful here!
</blockquote>

Pros

  • Flexible — works on any element
  • Explicit, hard to misuse

Cons

  • Verbose
  • Non-semantic
C

Both: <aside class="note"> + data-cli-callout

Support both approaches. <aside> as primary, attribute as fallback for any element.

<!-- Primary way -->
<aside class="note">A note</aside>

<!-- Also works -->
<p data-cli-callout="tip">A tip</p>

Pros

  • Maximum compatibility
  • Semantic primary path

Cons

  • Two code paths to maintain
