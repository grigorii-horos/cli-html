Definition Term <dt> — Visual Marker

Який маркер перед терміном у definition list?

A

Без маркера — тільки колір і відступ

Як зараз, але з кращим відступом між dt/dd парами.

HTML
  Hyper Text Markup Language

CSS
  Cascading Style Sheets
B

◆ або ▸ маркер перед терміном

Невеликий символ як у списках — візуально виділяє термін.

◆ HTML
  Hyper Text Markup Language

◆ CSS
  Cascading Style Sheets
C

Suffix :: після терміну

Двокрапка після терміну — класичний словниковий стиль.

HTML ::
  Hyper Text Markup Language

CSS ::
  Cascading Style Sheets
D

Config-driven: маркер у config.yaml

За замовчуванням — варіант B, але конфігурується через theme.

dt:
  color: blue bold
  indicator:
    marker: '◆'
    color: blue

dd:
  color: cyan
