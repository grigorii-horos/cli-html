### Bidirectional Text (BDI/BDO)

The bdi (Bidirectional Isolation) and bdo (Bidirectional Override) elements are
used for handling text in different directions.

#### BDI - Bidirectional Isolation

User مرحبا posted a comment.

Welcome to العربية language support!

The user שלום has joined the chat.

#### BDI with Usernames

Comment by דוד_כהן: תודה רבה

### Quote with Cite Attribute (data-cli-cite-enabled)

Default — double quotes, no cite indicator:

"To be or not to be, that is the question."

Custom prefix/suffix markers:

«Veni, vidi, vici.»

With cite attr — disabled by default (no external marker):

"All the world's a stage."

With cite enabled (data-cli-cite-enabled="true"):

"All the world's a stage. ↗"

Cite enabled with custom link color:

"The quick brown fox jumps over the lazy dog. ↗"

Custom brackets + cite enabled:

“Form follows function. ↗”
