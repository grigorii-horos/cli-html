Tables support customization at multiple levels with priority cascade:

 • td/th cell level (highest priority) - data-cli-color
 • tr row level - data-cli-tr-color
 • thead/tbody/tfoot section level - data-cli-thead-color, data-cli-tbody-color,
   data-cli-tfoot-color
 • Theme configuration (lowest priority)

## Priority Cascade Example

Demonstrates how colors are resolved when multiple levels specify styling:


┌───────────────┬────────────────┬───────────────────────────────┐
│ Item          │ Priority Level │ Color Source                  │
├───────────────┼────────────────┼───────────────────────────────┤
│ Cell Level    │ 1 (Highest)    │ data-cli-color on td          │
├───────────────┼────────────────┼───────────────────────────────┤
│ Row Level     │ 2              │ data-cli-tr-color on tr       │
├───────────────┼────────────────┼───────────────────────────────┤
│ Section Level │ 3              │ data-cli-tbody-color on tbody │
└───────────────┴────────────────┴───────────────────────────────┘
