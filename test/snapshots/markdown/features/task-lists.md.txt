# Task Lists

Task lists allow you to create checklists with checkboxes.

## Basic Task Lists

 • [✓] Completed task
 • [ ] Incomplete task
 • [✓] Another completed task
 • [ ] Yet another incomplete task

## Nested Task Lists

 • [✓] Phase 1: Planning
   ▪ [✓] Define requirements
   ▪ [✓] Create mockups
   ▪ [✓] Get approval
 • [ ] Phase 2: Development
   ▪ [✓] Setup project
   ▪ [✓] Implement core features
   ▪ [ ] Add tests
   ▪ [ ] Code review
 • [ ] Phase 3: Deployment
   ▪ [ ] Staging deployment
   ▪ [ ] Production deployment
   ▪ [ ] Monitor logs

## Task Lists with Rich Content

 • [✓] Bold task with emphasis
 • [ ] Task with inline code
 • [✓] Task with a link [https://example.com]
 • [ ] Task with strikethrough text
 • [✓] Task with highlighted text
