# Footnotes

Footnotes allow you to add notes and references without cluttering the main
text.

## Basic Footnotes

This is a sentence with a footnote⁽1⁾.

Here's another sentence with a different footnote⁽2⁾.

## Named Footnotes

You can use descriptive names for footnotes⁽3⁾.

This makes the markdown more readable⁽4⁾.

## Inline Footnotes

This is an inline footnote⁽6⁾.

## Footnotes with Formatting

## Multiple References

You can reference the same footnote multiple times⁽9⁾.

## Footnotes in Context

The study⁽11⁾ showed significant results.

Additional data⁽12⁾ supports the conclusion.
