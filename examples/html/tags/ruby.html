Ruby Annotation Examples

Ruby annotations are used to show pronunciation or meaning of characters, commonly used in East Asian typography (Japanese, Chinese, Korean).

Basic Ruby (Japanese Kanji)

Japanese word: 漢字かんじ (kanji)

Name: 東京とうきょう (Tokyo)

Country: 日本にほん (Japan)

Custom Colors

Accent base text: 漢字かんじ

Accent annotation: 東京とうきょう

Both customized: 日本にほん

Ruby with Fallback Parentheses

With rp tags: 漢字(かんじ)

Example: 富士山(ふじさん) (Mount Fuji)

Multiple Ruby Annotations

Sentence: 私わたしは 学生がくせいです

今日きょうは 良よい 天気てんきですね

Chinese Characters (Pinyin)

Hello: 你好nǐ hǎo

Thank you: 谢谢xiè xiè

China: 中国Zhōngguó

Korean Hanja

Korea: 韓國한국

School: 學校학교

Complex Example

The word 勉強べんきょう means "study" in Japanese. To say "I study", you would say: 私わたしは勉強べんきょうします。

Technical Terms

HTML: 超文本chāo wén běn

Computer: 電腦diàn nǎo

Internet: 互聯網hù lián wǎng

Custom Annotation Brackets (data-cli-prefix-marker / data-cli-suffix-marker)

Square brackets:

漢字かんじ

Angle brackets:

東京とうきょう

No brackets (empty):

日本にほん

Colored brackets:

勉強べんきょう

Custom brackets + annotation color:

富士山ふじさん

Multiple with different brackets in one sentence:

私わたしは 学生がくせいです。
