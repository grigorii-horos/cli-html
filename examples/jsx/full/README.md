# Full JSX Documents

Complete pages that combine many elements, built from data with components.

```sh
jsx examples/jsx/full/<file>.jsx
```

| File | Shows |
| --- | --- |
| [demo.jsx](demo.jsx) | Quick tour — headings, lists, blockquote, a small component |
| [components.jsx](components.jsx) | Composition: props, children, reusable pieces |
| [blog.jsx](blog.jsx) | Blog post — front matter, prose, code, tag list |
| [dashboard.jsx](dashboard.jsx) | Metrics, progress bars, incident table, checklist |
| [documentation.jsx](documentation.jsx) | API docs — code blocks, `kbd`, definition lists, links |
| [changelog.jsx](changelog.jsx) | Changelog from structured release data (conditional sections) |
| [recipe.jsx](recipe.jsx) | Recipe card — ingredients and numbered steps |
| [profile.jsx](profile.jsx) | Author profile — `fieldset`, `figure`, `details` |
