# JSX Tag Examples

Each file focuses on one element family, rendered with idiomatic JSX
(components, props, `.map()` over data).

```sh
jsx examples/jsx/tags/<file>.jsx
```

| File | Element(s) |
| --- | --- |
| [headers.jsx](headers.jsx) | `h1`–`h6`, dynamic heading from a prop |
| [text-styles.jsx](text-styles.jsx) | `strong`, `em`, `del`, `ins`, `mark`, `sub`, `sup`, `abbr`, `kbd` |
| [lists.jsx](lists.jsx) | `ul`, `ol`, nested lists from data |
| [table.jsx](table.jsx) | `table` built from an array of objects |
| [code.jsx](code.jsx) | inline `code` and highlighted `pre`/`code` blocks |
| [blockquote.jsx](blockquote.jsx) | `blockquote`, nested quotes, `cite` |
| [links.jsx](links.jsx) | `a` links, list generated from data |
| [details.jsx](details.jsx) | `details`/`summary` from data |
| [figure.jsx](figure.jsx) | `figure`/`figcaption` |
| [fieldset.jsx](fieldset.jsx) | `fieldset`/`legend` containers |
| [definitions.jsx](definitions.jsx) | `dl`/`dt`/`dd` from an object |
| [progress.jsx](progress.jsx) | `progress` and `meter` bars |
| [hr.jsx](hr.jsx) | `hr` separators |
| [kbd.jsx](kbd.jsx) | keyboard combos joined from arrays |
